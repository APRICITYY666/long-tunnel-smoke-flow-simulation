# 超长隧道烟气流动研究与3D示意模型

这是一个关于“超长隧道烟气流动”的简化三维示意模型，用于展示：

- 隧道中的主风流方向
- 高温烟源与热烟羽扩散
- 烟气层堆积与回流区
- 典型火灾/通风条件下的烟气运动趋势

## 目录说明

- `index.html`：交互式 3D 示意模型页面

## 运行方式

1. 直接在浏览器中打开 `index.html`
2. 或者使用本地静态服务器：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```

## 模型特点

- 采用 Three.js 构建的 3D 场景
- 表示了超长隧道的几何结构
- 通过颜色和粒子模拟烟气扩散过程
- 通过箭头标识主流方向
- 包含回流区、烟气堆积区和高温火源区域

## 适用场景

- 隧道火灾烟气运移分析
- 事故通风与排烟研究
- 教学展示与研究概念可视化
- 论文或汇报中的示意图基础模型

## 建议扩展

如果后续需要进一步完善，可以继续增加：

- 不同风速条件下的烟气分布变化
- 温度场和浓度场的可视化

## 说明

这是一个概念示意模型，不对应特定工程设计参数；它用于展示研究思路和空间分布特征。
